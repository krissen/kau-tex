# kau-tex

Karlstads universitet LaTeX packages: colours, headings, beamer themes and
the approved first page.

Under construction. Planned packages (one per theme, canonical 2025 brand
values):

- `kaucolors`
- `kaurubriker` (with a `kau_rubriker` compatibility wrapper)
- `kau-style`
- `kau-firstpage`
- `beamerthemeSingaporeKAU`
- `beamerthemeKAUposter`
- `beamerthemeKAUposterNOLOGO`
- `beamertheme-floral-kau` (thin configuration over `beamer-floral`)

The floral engine itself lives in the separate `beamer-floral` repository.
Commercial fonts and logo files are never bundled; packages use font
fallback chains.
